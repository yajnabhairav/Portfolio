## 📦 Getting Started

### Prerequisites
- Node.js (v18.0 or newer recommended)
- npm or pnpm or yarn

### Installation
```bash
# 1. Clone repository
git clone https://github.com/yajnabhairav/adarsh-narayan-portfolio.git
cd adarsh-narayan-portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

The application will be live at `http://localhost:3000`.

### Building for Production
```bash
# Build the client bundle
npm run build

# Start the full-stack server
npm run start
```
